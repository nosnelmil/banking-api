# Accounts API — Self-Assessment
 
## Tier 1 — Production Gate (must pass)
- [ ] All endpoints return correct, specific status codes
- [ ] All inputs are validated with a standard error envelope
- [ ] Every endpoint requires authentication where appropriate
 
## Tier 2 — Baseline Maturity
- [ ] Full CRUD implemented and tested
- [ ] OpenAPI contract complete and matches code
- [ ] Versioning strategy in place (v1/v2)
 
## Tier 3 — Advanced Patterns
- [ ] Idempotency keys on sensitive operations
- [ ] Structured logging, metrics, and tracing
- [ ] Async used appropriately for I/O-bound work
